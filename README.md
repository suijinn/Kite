# Kite

[![ci](https://github.com/suijinn/Kite/actions/workflows/ci.yml/badge.svg)](https://github.com/suijinn/Kite/actions/workflows/ci.yml)

Windows エクスプローラーの代替を目指す、C++ 製の軽量ファイラー。
インストール不要、依存 DLL なし、起動は 0.2 秒前後。

名前は「凧」から。軽く、速く、風向きが変わればすぐ向きを変える。菱形のシルエットは
ペイン分割の暗喩でもある。

現在は**プロトタイプ（v0.1）**。日常のファイル操作はひととおり動く。検索・サムネイル・
表示形式の切り替えはまだ無い（→ [ROADMAP](docs/ROADMAP.md)）。

## ダウンロード

[Releases](https://github.com/suijinn/Kite/releases/latest) の
`kite-vx.y.z-win-x64.zip` を展開する。中身は**同じフォルダのまま**置くこと。

| ファイル | 役割 |
| --- | --- |
| `kite.exe` | 本体 |
| `kite_shellhost.exe` | 右クリックメニューとアイコンを担当する別プロセス |
| `config\` | 設定の置き場所。フォルダごと持ち運べる（下記「設定」） |

`kite.exe` はホストを**自分と同じフォルダから**起動する。片方だけを移すと、右クリックで
「シェルメニューを表示できませんでした」になる。

## 主な機能

- **タブとペイン分割** — 左右／上下、入れ子、比率はドラッグで変更。タブはドラッグで
  並べ替え・別ペインへ移動でき、ウィンドウの外へ落とすと新しいウィンドウになる。
  枚数が増えればバーが折り返す。タブバーは縦置きにもできる
- **セッション** — 分割レイアウトごと名前を付けて保持し、即座に切り替え。終了時に保存される
- **サイドバー** — クイックアクセス／ブックマーク／ドライブ。区画ごとに折り畳め、
  ドラッグで並べ替えられる。ブックマークは `Alt+Shift+1..8` で直行
- **行き先の検索（`Ctrl+P`）** — ブックマーク・開いているタブ・ドライブを 1 つの入力欄で
  絞り込んで飛ぶ。`>` を打つとそのままコマンドパレット（`Ctrl+Shift+P`）に切り替わる
- **全操作にキーを割り当てられる** — `F1` で一覧、`Ctrl+Shift+,` の設定画面か `keys.ini` で変更。
  割り当てを覚えていなくても、コマンドパレットから全操作に届く
- **ファイル操作** — 新規作成／リネーム／削除（ごみ箱・完全）／コピー・切り取り・貼り付け／
  パス・名前のコピー。`Ctrl+Z` で名前の変更・新規作成・移動・コピー・ごみ箱への削除を戻せる
  （完全削除だけは戻らない）。同じフォルダへの貼り付けは `_copy` の複製になる
- **名前はその場で編集** — リネームは対象の行、新規作成はカーソルの 1 行下、セッション名は
  そのチップの中。どれの名前を訊かれているかが位置で分かる
- **一覧の列** — 名前・拡張子・サイズ・更新日時・経過時間（「5 分前」「3 日前」）。
  見出しの縁をドラッグで幅、見出しそのものをドラッグで並び、設定画面で出す・出さない。
  `Ctrl+Shift+G` で、並べ替えている基準ごとに見出しを挟んでまとめる
- **エクスプローラーと同じ右クリックメニューと実アイコン** — アイコンオーバーレイ
  （OneDrive の同期状態、TortoiseGit の変更）もそのまま出る。拡張動詞は `Shift` を
  押したときだけ
- **仮想フォルダ** — 「PC」「ごみ箱」「ネットワーク」を開いて辿れる。ごみ箱からの復元は
  `Alt+R`。書庫はフォルダとして開ける（`.zip` / `.cab` はどの Windows でも、
  `.tar` / `.tar.gz` / `.7z` / `.rar` は Windows 11 23H2 以降）
- **ネットワーク** — `\\server` を開けば共有の一覧。資格情報が要る相手には `Ctrl+Shift+L`
- **固まらない** — 列挙もアイコン取得も、**削除・コピー・移動も**常にワーカースレッド。
  大きなコピーの最中でも別のタブへ移れるし、**別の場所へのファイル操作はその裏で
  同時に走る**（同じ場所を奪い合うものだけが順番待ちになる）。ネットワーク・USB・
  クラウドが遅くても操作を受け付け続ける。クラウドのプレースホルダは実体化しない
- **ドラッグ＆ドロップ** — Kite 内、エクスプローラーとの相互。同一ボリュームは移動・
  別ボリュームはコピー、`Ctrl` でコピー固定・`Shift` で移動固定
- **選択と移動** — 範囲・トグル・全選択・反転、余白から引く選択の枠。`Space` で付けた印は
  カーソル移動で消えない。文字キーを打てばその名前の行へ飛ぶ（型入力ジャンプ）
- **アドレスバー（`Ctrl+L`）** — パンくずと同じ 1 行。打てばフォルダ名が補完される
- **見た目** — ダーク／ライト（タイトルバーと右クリックメニューも追従）、文字サイズの変更、
  配色は設定ファイルで上書き可能
- **日本語／英語 UI** — OS の設定から自動判定。`lang.<code>.ini` を置けば言語を追加できる。
  IME の変換中の文字は Kite 自身が入力欄の中に描く
- **単一インスタンス** — フォルダを渡して起動すると、動いている Kite の新しいタブとして
  開いて前面に出る。別の窓が欲しいときは `Ctrl+N`

## キー操作

`F1` でいつでも全一覧が出る。3 つの数字列が並行しているのが基本方針。

| | |
| --- | --- |
| `Ctrl+1..9` | タブを選択 |
| `Alt+1..8` | セッションを選択 |
| `Alt+Shift+1..8` | ブックマークへ移動 |

主なもの:

| 操作 | キー |
| --- | --- |
| 左右に分割／上下に分割／ペインを閉じる | `Alt+V` / `Alt+H` / `Alt+W` |
| 次／前のペイン | `Tab` / `Shift+Tab` |
| 新しいタブ／閉じる／閉じたタブを戻す | `Ctrl+T` / `Ctrl+W` / `Ctrl+Shift+T` |
| 新しいセッション／セッション名を変更 | `Ctrl+Alt+N` / `Ctrl+Alt+R`（チップのダブルクリックも可） |
| 新しいウィンドウ | `Ctrl+N` |
| 親フォルダへ | `Backspace` / `Alt+Up`（一覧先頭の `..`、余白のダブルクリックも可） |
| 戻る／進む | `Alt+Left` / `Alt+Right`（マウスの戻る／進むボタンも可） |
| パスを編集／絞り込み | `Ctrl+L` / `Ctrl+F` |
| 行き先の一覧／コマンドパレット | `Ctrl+P` / `Ctrl+Shift+P` |
| 元に戻す／ごみ箱から復元 | `Ctrl+Z` / `Alt+R` |
| コンテキストメニュー | `Menu` キー、または右クリック（拡張は `Shift+F10` / `Shift`+右クリック） |
| 現在のフォルダーのコンテキストメニュー | `Ctrl+Menu`（拡張は `Ctrl+Shift+F10`） |
| ここでターミナルを開く | ``Ctrl+` `` / `Alt+T` |
| 並べ替え（名前／拡張子／サイズ／日時／経過時間） | `Ctrl+Shift+1..5`（見出しのクリックも可。同じ列でもう一度押すと昇順・降順） |
| 隠しファイル／フォルダを先頭に／まとめる | `Ctrl+H` / `Ctrl+Shift+F` / `Ctrl+Shift+G` |
| 列幅を既定に戻す | `Ctrl+Alt+0`（縁のダブルクリックで 1 列だけ戻す） |
| 文字を大きく／小さく／既定へ | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| サイドバーの表示切り替え／ダーク・ライト切り替え | `Ctrl+B` / `Ctrl+Shift+M` |
| 設定画面 | `Ctrl+,`（キー割り当ては `Ctrl+Shift+,`、設定フォルダを開くのは `Ctrl+Alt+,`） |

`Alt+V` / `Alt+H` を分割に充てているのは、JIS 配列でも押しやすいため
（`Ctrl+\` は JIS では位置が異なる）。

変更は `Ctrl+Shift+,` の設定画面か、`keys.ini` を編集して `Ctrl+Alt+C` で再読み込み。初回起動時に
全デフォルトを書き出してあるので、そのファイルがそのまま一覧兼リファレンスになる。

```ini
[keys]
pane.split_left_right = Ctrl+Alt+V   ; 追加（複数行書けば複数の割り当て）
tab.close             = none         ; 既定を全部外す
```

## 設定

置き場所は 2 通り。**`kite.exe` の隣に `config` フォルダが在ればそこ**、無ければ
`%APPDATA%\Kite\`。zip には `config` が入っているので、展開してそのまま使えば設定を含めた
全部がそのフォルダの中で完結する（フォルダごと USB へ移しても設定が付いて来る）。`config`
を消せば `%APPDATA%\Kite\` に切り替わる。今どちらを使っているかは `Ctrl+Alt+,` で確かめられる。

> `Program Files` や書き込み禁止のメディアに展開した場合、設定は保存されない。初回起動時に
> 「書き込めませんでした」と出るので、書き込める場所へ移すこと。

中身はすべてプレーンな INI で、手で編集できる。

| ファイル | 内容 |
| --- | --- |
| `settings.ini` | テーマ・言語・表示設定・ウィンドウ位置・配色の上書き・サイドバーの並び・一覧の列 |
| `keys.ini` | キー割り当て |
| `sessions.ini` | セッション名とペイン分割レイアウト（タブのパスを含む） |
| `bookmarks.ini` | ブックマーク |
| `lang.<code>.ini` | 任意。UI 文字列の追加・上書き（新言語の追加に再ビルド不要） |

よく変える項目は `Ctrl+,` の設定画面にもある。配色は `[theme.dark]` / `[theme.light]` で
個別に上書きできる。

```ini
[theme.dark]
accent  = 3E7BFA
list_bg = 1B1E24

[ui]
font_family = Yu Gothic UI
font_size   = 13     ; 既定の文字サイズ。8〜24 の整数（設定画面の選択肢に丸める）
font_scale  = 1.0    ; Ctrl++ / Ctrl+- が書き換える倍率。上の値に掛かる
```

文字の大きさは 2 つの値で決まる。`font_size` が **既定の文字サイズ**（`Ctrl+0` が
戻る先）で、`font_scale` がその上に掛かる倍率（`Ctrl++` / `Ctrl+-`）。どちらも
行やバーの高さごと拡大するので、大きくしても文字が切れない。両方とも設定画面
（`Ctrl+,`）の「外観」にある。

## ソースからビルドする

Visual Studio 2022（C++ ワークロード）だけあればよい。CMake・Ninja・ctest はすべて VS に
同梱されている。**x64 Native Tools Command Prompt for VS 2022** から:

```bash
cmake --preset release
cmake --build --preset release
ctest --preset release
```

出力は `build\release\` に `kite.exe`・`kite_shellhost.exe`・`kite_tests.exe`。
シェルの選び方（素の Developer PowerShell は x86 を向く）や CI の内容は
[docs/architecture.md](docs/architecture.md) に。
